# Phase 詳細設計の雛形

`/specramo:phase-design` が使う雛形。導入先の `.specramo/templates/phase-design.md` に同じ名前の file を置くと、この雛形の代わりに使われる。判断の無い節は作らない (「変更なし」で節を埋めない)。

```markdown
# Phase 詳細設計: PR #[n] [Phase 名]

- 作業計画書: [作業計画書への link] の PR #[n]

## 担当する受け入れ条件と担い手

| 条件 | 担い手 |
| --- | --- |
| [作業計画書の完了条件が引用する条件の文] | [その条件を満たす型 / 操作。条件 1 行につき 1 つ] |

## 決定

1. **[決定の 1 文]** [理由。既存 code で確かめた事実のうち、判断を変えるものだけを下位 bullet に添える]

## 処理フロー (順序か分岐があるときだけ)

1. [手順]

## 契約 (型か公開 method を新しく作るときだけ)

- 不変条件: [インスタンスが成立している間ずっと満たす条件] / 守る場所: [constructor / factory / usecase / DB の制約]
- 事前条件: [呼び出し側が満たす条件] / 守る場所:
- 事後条件: [正常終了時に提供側が保証すること] / 守る場所:

## テスト観点

- fixture: [完了条件が引用する条件の数だけ、区別できる行を並べる]
- mutation check: [壊す条件を 1 つ。壊したときに fail する test]

## 実装メモ

| 決定 | 実装 |
| --- | --- |
| [決定の番号] | [file 名 / method 名 / 実行 command] |

### 変更対象 file

- [実在を確かめた file。新規なら「新規」と添える]
```
